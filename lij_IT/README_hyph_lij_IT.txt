Converted from the upstream TeX patterns using libhyphen 2.8.9 substrings.pl, with UTF-8 encoding and hyphenation minima of 2/2. A NEXTLEVEL declaration was inserted before all patterns to disable libhyphen's default apostrophe splitting, since the upstream source handles apostrophes explicitly.
